# EventHub — Event & Appointment Booking App

**ITP107 Midterm Task | Section: [3IT-B] | Group: [2]**

A Flutter mobile app that lets users browse events/appointments and book a slot,
built to demonstrate Stateless/Stateful widgets, gesture handling, form validation,
custom theming, and responsive layout.

## 🚀 How to Run
1. Ensure Flutter SDK is installed (`flutter doctor`)
2. Clone this repo
3. Run `flutter pub get`
4. Run `flutter run`

## ✨ Features
- Browse events in a responsive list/grid
- Tap for details, double-tap to favorite, long-press for quick actions
- Book an event via a validated multi-field form
- Custom color theme and typography throughout

## 📂 Project Structure
See `/lib` for source code — organized into `models/`, `theme/`, `screens/`, `widgets/`.
